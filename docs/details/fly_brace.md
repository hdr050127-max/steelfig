# Fly brace: rafter bottom flange to purlin

**Parts**: an angle each side of the rafter from the bottom flange up to the purlin web; one bolt through the
purlin web and the angle leg; a cleat plate welded to the rafter flange tip with one bolt.
**Rules** (`assembly.fly_braces_on`):
- the brace bolts to the purlin web through the lower lap / cleat hole, B above the purlin bottom (55 mm for the
  150–250 series) [Stramit guide: fly bracing, cleat table]; never welded to the purlin [Stramit guide]
- long leg flat on the flange-free face of the purlin web: upslope face of a Z (its bottom flange is downslope),
  back of a C [Stramit section geometry]
- bolt ≥ 1.75 d_f from the angle end and from the web edges [AS 4100 Table 9.5.2]; angle end stops under the
  top flange
- brace at about 45° (checked 35–55°): reach set from the rafter depth
- lower end 85 mm below the flange so the leg clears the flange; cleat plate in the brace plane, one bolt
- angle 50x50x5 EA + M12 for rafters up to 360 deep, 75x50x6 UA + M16 above: ASSUMPTION
**Sources**: Stramit Detailing & Installation Guide; AS 4100 Cl 9.5. See `SOURCES.md`.
