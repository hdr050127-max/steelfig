# Pinned base plate

**Parts**: base plate; 40 mm grout; four holding-down bolts inside the flange faces; footing (schematic).
**Rules**: plate thickness 20 / 25 / 32 / 40 mm by column depth; plate = d + 140 by bf + 100; bolts 60 mm inside
the flange faces, 2 × 60 mm about the web; HD bolt M20 / M24 / M24 / M30.
**Sources**: TTW course base plate table (p22 of the course drawings); ASI standardised connections (pinned base).
**To verify**: bolt position 60 mm inside the flange faces matches TTW's table (checked for 610UB113: spacing 487);
